# Блогер-миллионер — детский кликер

Простая тапалка для Яндекс Игр: тапай по блогеру, зарабатывай, прокачивай канал и скупай роскошь.
Все персонажи вымышленные (Тапыч, Лайкуша, Турбо-Бро) и нарисованы кодом (SVG), внешних файлов нет.

## Что есть
- выбор блогера, анимация тапа, летящие цифры и монетки, звуки (WebAudio);
- **Прокачка** (доход за тап): телефон, микрофон, лампа, камера, монтажёр, дрон, команда;
- **Доход** (в секунду): короткие ролики, стримы, реклама, мерч, студия, продюсерский центр, шоу на ТВ, свой бренд;
- **Роскошь**: самокат → спорткар → особняк → яхта → самолёт → остров → ракета, каждая покупка +8% к доходу и появляется на сцене;
- **Кубки** за подписчиков (1 тыс., 10 тыс., 100 тыс., 1 млн…), каждый +15% к доходу, с конфетти;
- звания: от «Новичка» до «Миллионера», «Миллиардера» и «Легенды»;
- золотая звезда «Хайп» пролетает по экрану, если её поймать — доход ×7 на 15 секунд;
- доход, пока игрока не было (до 2 часов), можно удвоить за рекламу;
- сохранение в браузере и в облаке Яндекса.

## Yandex Games SDK
`LoadingAPI.ready()`, `GameplayAPI.start/stop`, полноэкранная реклама при входе, реклама за вознаграждение
(×2 к доходу на 2 минуты, удвоение оффлайн-дохода), облачные сохранения. Без SDK (локально) награды выдаются сразу.

## Запуск и публикация
- Проверить: дважды кликнуть `index.html`.
- Собрать архив для Яндекса: `./build.sh` → `blogger-clicker.zip`.
